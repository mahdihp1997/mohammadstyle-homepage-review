## Browser compatibility fix

The actual LAN test reproduced successful OTP but no availability request because creating the client request UUID threw before fetch.

It sets the version/variant bits and refuses missing/failed cryptographic randomness. No Math.random, clocks or weakened token generation are used. All9 browser UUID call sites in Booking, account cancellation and admin forms/media/policy use this shared helper.
