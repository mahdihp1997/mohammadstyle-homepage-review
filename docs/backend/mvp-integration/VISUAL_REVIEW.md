# Actual UI visual review

Canonical UI is the running Next.js app, not preview.html or a diagram. Playwright captures actual `/admin` workspaces and `/portfolio` at 1440×900, 1024×768, 390×844 and 375×812, with full-page and fold images. The owner review package links individual PNGs. Only explicitly synthetic geometric/video patterns are uploaded for these captures. No original recognizable client image is exported.

Charcoal surfaces, champagne highlights, restrained outlines, Persian RTL type and right navigation follow the approved visual direction. Existing Homepage and Booking visual source is preserved. The public review retains system fonts and Phase 01 placeholders. Original private font binaries/reference boards/photos are omitted.

Intentional departures from decorative concept boards: genuine bounded API counts and empty states replace imagined revenue/charts/appointments; branch two/unknown prices remain unconfigured. Native labeled forms, server errors/CAS feedback and complete policy editors replace unreadable mockup controls. Staff roles/qualifications and published calendar evidence are factual server records. Booking uses the existing Jalali calendar; admin configuration fields explicitly label Gregorian dates and branch IANA time.

Mobile navigation uses a modal right drawer with focus trap, Escape, body lock, inert background and focus return. Gallery image detail uses a native accessible dialog, Escape/backdrop/close and explicit opener focus restoration. Full image crops are preserved. Video uses native controls, no autoplay, safe poster and streamed/ranged optimized output.

Browser tests cover all workspaces, row/form writes, safe no-auth/limited editor states, manual upload, categorization, explicit evidence/publication, immediate revocation, gallery filters/detail focus, video playback, admin cancellation reason/history and calendar review. No horizontal scrolling, broken derivative images or page JavaScript errors are accepted by the captures. Test failures found during implementation (gallery opener focus, error focus timing, required-field exact label test selectors and repeated-fixture locator ambiguity) were fixed and rerun; final evidence records actual outcomes.

Owner approval is still required. Production authentication, commercial configuration, legal consent review, cloud delivery/retention, responsive behavior on physical devices and real operational data are not claimed as completed deployment validation.
