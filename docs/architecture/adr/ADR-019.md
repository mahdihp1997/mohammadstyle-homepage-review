# ADR-019 — Readable context views and explicit sequence alternatives

Status: PROPOSED; Phase03A hardening2026-10-29. Architecture approval pending.

## Decision

Keep complete source ERD and add bounded-context projections, a layered module overview/exact DAG and a source-driven payment sequence with mutually exclusive outcomes.

## Alternatives

Shrinking one full ERD or a hairball dependency graph hides reviewable relationships and alternatives.

## Consequences

Projection coverage/edge checks and actual SVG/PNG rendering are static evidence only, never backend testing.

No03B implementation is authorized by this record.
