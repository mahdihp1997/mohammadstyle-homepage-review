# ADR-014 — Temporal staff branch membership periods

Status: PROPOSED; Phase03A hardening2026-10-29. Architecture approval pending.

## Decision

One UUID per stint; daterange half-open non-voided same-branch overlap exclusion, period-specific offering eligibility and same-stint schedule FK.

## Alternatives

Updating one permanent staff+branch row loses historical membership; active-only uniqueness permits historical overlap.

## Consequences

Explicit close/rejoin/correction workflow, no FK reparenting; cross-row shift containment tests still required.

No03B implementation is authorized by this record.
