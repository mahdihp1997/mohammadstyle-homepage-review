# ADR-007 — Versioned integer Rial and explicit Toman adapter

Status: **PROPOSED**, pending Phase 03A review. Date: 2026-10-29.

## Context and decision

Store bigint v1 Rial, API decimal strings, exact checked conversion and whole-Toman-compatible rounding/constraints for MVP.

## Alternatives and trade-off

Floating money or implicit gateway units can mischarge; unversioned redenomination corrupts historical evidence.

## Consequences and revisit trigger

Owner/merchant must confirm the 10-v1-Rial mapping. Future sub-Toman/multicurrency needs a new contract; intermediate arithmetic uses BigInt.

No implementation or deployment is authorized by this ADR. Revisit on approved business requirements, measured load, gateway capabilities or a demonstrated invariant failure; record a superseding ADR rather than silently rewriting accepted decisions.
