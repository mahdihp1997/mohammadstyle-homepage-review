# ADR-013 — Content-only quote integrity versus request identity

Status: PROPOSED; Phase03A hardening2026-10-29. Architecture approval pending.

## Decision

Non-unique SHA256/JCS MS_QUOTE_CONTENT_V2, immutable exact payload and independent actor/route/key idempotency; accept duplicate content hashes.

## Alternatives

Unique digest prevents independent customers requesting identical content; salting the digest with customer IDs conflates integrity and identity.

## Consequences

New versioned artifact/DTO fields; ownership/expiry remain separately guarded. See QUOTE_HASH_CONTRACT.md and V19–V21.

No03B implementation is authorized by this record.
