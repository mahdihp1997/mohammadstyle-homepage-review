# ADR-015 — Persisted revisionless drafts and monotonic admitted plans

Status: PROPOSED; Phase03A hardening2026-10-29. Architecture approval pending.

## Decision

plan_committed distinguishes revisionless DRAFT/CANCELLED/EXPIRED from every admitted state; atomic admission clears draft TTL and sets required revision.

## Alternatives

Inventing a revision for an abandoned draft or dropping draft abort edges misrepresents lifecycle.

## Consequences

Disjoint future DTOs and draft-create contract; monotonic flag/content/history grants need actual03B tests.

No03B implementation is authorized by this record.
