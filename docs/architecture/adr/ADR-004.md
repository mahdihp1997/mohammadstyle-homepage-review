# ADR-004 — Branch offerings and resource requirements

Status: **PROPOSED**, pending Phase 03A review. Date: 2026-10-29.

## Context and decision

Shared Service metadata; branch-specific verified values/revision, explicit staff and resource-kind requirements.

## Alternatives and trade-off

Global service tariff/duration or qualification-as-availability loses branch/day/resource distinctions.

## Consequences and revisit trigger

Quotes snapshot configuration; unknown or inactive offerings remain unbookable. Admin configuration does not require source edits.

No implementation or deployment is authorized by this ADR. Revisit on approved business requirements, measured load, gateway capabilities or a demonstrated invariant failure; record a superseding ADR rather than silently rewriting accepted decisions.


Hardening clarification: branch membership is temporal per ADR014; offering staff eligibility references one explicit stint and returning staff receive new eligibility rows.
