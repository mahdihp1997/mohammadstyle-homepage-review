# ADR-002 — PostgreSQL occupancy is the capacity authority

Status: **PROPOSED**, pending Phase 03A review. Date: 2026-10-29.

## Context and decision

One global resource identity per staff member, unit physical resources, GiST exclusion on unreleased half-open intervals; PostgreSQL 18 proposal and Prisma plus reviewed raw SQL.

## Alternatives and trade-off

Redis locks expire independently of DB state; only checking a SELECT can race; capacity counters alone do not capture temporal overlap.

## Consequences and revisit trigger

Exclusion/extension/raw SQL must be preserved through real migration/drift tests. Ranges are not assumed fully represented by Prisma.

No implementation or deployment is authorized by this ADR. Revisit on approved business requirements, measured load, gateway capabilities or a demonstrated invariant failure; record a superseding ADR rather than silently rewriting accepted decisions.
