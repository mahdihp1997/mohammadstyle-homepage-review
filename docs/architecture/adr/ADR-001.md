# ADR-001 — Modular monolith and one-way context ports

Status: **PROPOSED**, pending Phase 03A review. Date: 2026-10-29.

## Context and decision

Use one Nest application plus worker deployment, narrow module ports and outer application workflows. Scheduling/Policies accept opaque booking references; Booking does not import Payments/Notifications.

## Alternatives and trade-off

Microservices add distributed consistency/operations; direct cross-repository imports or forwardRef conceal cycles.

## Consequences and revisit trigger

Shared transaction context must remain explicit. A later service extraction needs evidence of independent scale/ownership, not anticipation.

No implementation or deployment is authorized by this ADR. Revisit on approved business requirements, measured load, gateway capabilities or a demonstrated invariant failure; record a superseding ADR rather than silently rewriting accepted decisions.
