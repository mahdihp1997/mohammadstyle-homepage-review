# ADR-016 — Evidence-driven indexes with exact FK target preservation

Status: PROPOSED; Phase03A hardening2026-10-29. Architecture approval pending.

## Decision

Retain integrity/concurrency arbiters and selected FK/recovery support; drop blind actor indexes, unreferenced helper keys and duplicate context-prefix variants; defer query candidates.

## Alternatives

One index per FK or speculative query increases write/storage cost; removing referenced unique keys breaks composite FK validity.

## Consequences

Archive/redact User/Business; physical-erasure workflow and query candidates need measured EXPLAIN review. No measured speedup claimed.

No03B implementation is authorized by this record.
